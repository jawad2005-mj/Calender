# 📅 Interactive Calendar App

A beautiful, responsive calendar application built with Streamlit featuring smooth animations and an intuitive user interface.

## ✨ Features

- 📆 **Year Calendar View** - Display full year calendars
- 📅 **Month Calendar View** - View detailed monthly calendars
- ➕ **Event Management** - Add, view, and delete events with ease
- 🎨 **Beautiful UI** - Gradient backgrounds and smooth animations
- 💾 **Persistent Storage** - Events are saved locally in JSON format
- 📱 **Fully Responsive** - Works seamlessly on any screen size

## 🚀 Quick Start

### Prerequisites

- Python 3.7 or higher
- pip (Python package installer)

### Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/calendar-app.git
cd calendar-app
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

### Running the App

Run the Streamlit app with:
```bash
streamlit run app.py
```

The app will automatically open in your default web browser at `http://localhost:8501`

## 📖 Usage

### Year Calendar
1. Select "📆 Year Calendar" from the sidebar
2. Enter the desired year
3. Click "🔍 Show Calendar" to display the full year

### Month Calendar
1. Select "📅 Month Calendar" from the sidebar
2. Choose year and month
3. Click "🔍 Show Month" to view the calendar

### Add Events
1. Select "➕ Add Event" from the sidebar
2. Pick a date using the date picker
3. Enter event name and optional details
4. Click "💾 Save Event"

### View Events
1. Select "👀 View Events" from the sidebar
2. Browse all your saved events
3. Expand any event to see details
4. Delete events using the 🗑️ button
